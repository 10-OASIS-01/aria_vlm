    Set up once

    What this machine needs before the console can run trials. Day to day, everything starts from Live.

    1

    Start the console

    On the GPU machine. The model loads in about 10 s; then open this page. It keeps running in tmux until you stop it.

    bash aria_vlm/scripts/service.sh start
    2

    Pair the glasses

    Once per pair: device certificates and USB or Wi-Fi setup, as in the aria2_ros2 README. This should list the glasses:

    ros2 run aria_ros2 aria_device info
    3

    Point the console at ROS

    In aria_vlm/.env: where aria2_ros2 lives, its Fast DDS profile (large buffers, or frames drop), and the photo the test camera plays.

    ARIA_ROS_WORKSPACE · ARIA_FASTDDS_PROFILE · ARIA_FAKE_IMAGE
    Aria nodeExisting ROS topicPurpose
    PUBLISHES/aria/rgb/image_rawVision: RGB with sensor-data QoS
    PUBLISHES/aria/gazeGaze: available, unused by the MVP planner
    PUBLISHES/aria/audioMicrophone: interleaved int32 samples
    SUBSCRIBES/aria/ttsText for onboard speech

    The /guidance controls belong to guidance_node. No changes to the Aria node are required.
