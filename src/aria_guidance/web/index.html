03 / LAB HANDOFF

Connect the glasses

Run the bridge beside the existing Aria ROS 2 infrastructure.

Read the deployment guide ↗
1

Start the backend

Install the model dependencies, set ARIA_MODEL_PATH, then start one service process on a GPU workstation.

bash scripts/service.sh start
2

Join aria2_ros2

Build the bridge in the ROS 2 Humble workspace. Use the same domain as the Aria node and set the backend URL.

ros2 launch aria_planner_bridge bridge.launch.py
3

Give a goal, then act

Type a goal or use push-to-talk. The bridge samples the camera and publishes the next instruction to /aria/tts.

/planner/goal · /planner/command
Aria nodeExisting ROS topicPurpose
PUBLISHES/aria/rgb/image_rawVision: RGB with sensor-data QoS
PUBLISHES/aria/gazeGaze: available, unused by the MVP planner
PUBLISHES/aria/audioMicrophone: interleaved int32 samples
SUBSCRIBES/aria/ttsText for onboard speech

The /planner controls belong to the new bridge. No changes to the Aria node are required.
